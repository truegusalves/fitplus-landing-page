# 🏋️ Fit+ | Landing Page

Landing page moderna, limpa e totalmente responsiva desenvolvida para um aplicativo fitness fictício. O projeto foi construído utilizando apenas **HTML5** e **CSS3**, com foco em boas práticas de estruturação, acessibilidade e design responsivo.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estrutura semântica da página.
* **CSS3:** Estilização avançada com variáveis CSS (`--variables`), Flexbox, gradientes e design responsivo (`@media queries`).
* **Google Fonts:** Tipografias *DM Sans* e *Space Grotesk*.

## ✨ Funcionalidades e Destaques

* **Design Responsivo:** Layout adaptável para dispositivos móveis e desktops, alterando a disposição dos elementos conforme o tamanho da tela.
* **Navegação Suave:** Rolagem suave (*smooth scroll*) com ajuste de espaçamento para o menu fixo.
* **Acessibilidade:** Uso de atributos `aria-label` e marcações semânticas para melhorar a experiência de leitores de tela.
* **Efeitos Visuais:** Elementos em destaque utilizando gradientes radiais, filtros de sombra (`drop-shadow`) e transições suaves em botões.
